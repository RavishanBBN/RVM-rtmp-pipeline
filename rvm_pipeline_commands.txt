Normal VR RAW/RVM switching setup

Run these three commands in three separate PowerShell windows.
Keep all three running while using the Unity app.
Open the Unity menu and switch between RAW and RVM using the Stream: RAW / Stream: RVM menu rows.


1. Start MediaMTX

cd C:\Users\USER\Downloads\mediamtx_v1.18.1_windows_amd64
.\mediamtx.exe


2. Start raw republisher

while ($true) {
  ffmpeg -fflags +genpts+discardcorrupt -err_detect ignore_err -rtmp_live live `
    -use_wallclock_as_timestamps 1 `
    -i rtmp://127.0.0.1/live/drone `
    -map 0:v:0 -an `
    -c:v libx264 -preset ultrafast -tune zerolatency `
    -profile:v baseline -bf 0 `
    -g 20 -keyint_min 20 -sc_threshold 0 `
    -pix_fmt yuv420p `
    -f flv rtmp://127.0.0.1:1936/drone_raw

  Write-Host "raw republisher exited, restarting in 2 seconds..."
  Start-Sleep -Seconds 2
}


3. Run RVM relay for masked-person view

cd C:\Users\USER\Desktop\Hattan\RVM-rtmp-pipeline
.\.venv\Scripts\python.exe .\rtmp_avatar_stream.py `
  --variant mobilenetv3 `
  --checkpoint .\rvm_mobilenetv3.pth `
  --device auto `
  --input-rtmp rtmp://127.0.0.1:1936/drone_raw `
  --output-rtmp rtmp://127.0.0.1:1936/rvm `
  --mode black `
  --silhouette-color 0 0 0 `
  --background-color 255 255 255 `
  --input-resize 640 360 `
  --input-fps 10 `
  --input-queue-size 1 `
  --frame-timeout-seconds 8 `
  --downsample-ratio 0.2 `
  --bitrate-mbps 1 `
  --process-every-nth-frame 1 `
  --reconnect-delay-seconds 2

Notes for modes:

- --mode black
  person becomes a solid silhouette color
  background uses --background-color

- --mode foreground
  person keeps the real RGB appearance
  background uses --background-color

- --mode background
  background keeps the real RGB appearance
  person uses --silhouette-color

- --mode emoji
  person area is filled with the emoji pattern
  background uses --background-color


Unity menu RAW/RVM switching

The Unity menu has Stream: RAW and Stream: RVM rows.
It also has Delay and Slow Motion controls.

For normal testing, keep all three commands running:

1. Start MediaMTX
2. Start raw republisher
3. Run one RVM relay mode

Then open the Unity menu and select:

- Stream: RAW uses:
  http://192.168.1.7:8889/drone_raw/whep

- Stream: RVM uses:
  http://192.168.1.7:8889/rvm/whep

You do not need to rebuild Unity or stop/restart commands just to switch RAW/RVM.

Delay controls in Unity:

- Delay row toggles delayed playback on/off.
- 3s, 5s, and 10s chips set the delay preset and turn delay on.
- Delay and Slow Motion are mutually exclusive.

Slow Motion controls in Unity:

- Slow Motion row toggles slow playback on/off.
- 0.25x, 0.5x, and 0.75x chips choose the playback speed.
- Slow Motion starts from the buffered history and plays it back at the selected speed.
- Delay and Slow Motion are mutually exclusive.

No extra PowerShell commands are needed for Delay or Slow Motion. They use the Unity playback buffer.

If the Wi-Fi router changes

The local RTMP commands stay the same.

The Quest/Unity WHEP URLs may change because your PC IP may change.

Find the new PC IP:

ipconfig

Look for the active Wi-Fi adapter IPv4 Address.

Then update these fields in WebRtcVideoReceiver:

rawWhepUrl:
http://NEW_IP:8889/drone_raw/whep

rvmWhepUrl:
http://NEW_IP:8889/rvm/whep

whepUrl:
http://NEW_IP:8889/rvm/whep

Also update MediaMTX config if needed:

webrtcAdditionalHosts: [127.0.0.1, NEW_IP]

Then restart MediaMTX.

Quest browser quick tests:

http://NEW_IP:8889/drone_raw/

http://NEW_IP:8889/rvm/


If you want to change colors

The RVM relay command uses:

--silhouette-color R G B
--background-color R G B

Current values:

--silhouette-color 0 0 0
--background-color 255 255 255

Examples:

Black silhouette:
--silhouette-color 0 0 0

White silhouette:
--silhouette-color 255 255 255

Red silhouette:
--silhouette-color 255 0 0

Green background:
--background-color 0 255 0

Blue background:
--background-color 0 0 255

Gray background:
--background-color 128 128 128

Notes:

- Values are RGB, each from 0 to 255.
- Change the values in the RVM relay command, then restart the relay.
- Background color is the non-person area in black and foreground modes.
- Silhouette color is the person color in black and background modes.
